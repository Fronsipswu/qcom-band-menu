# QBM translations. The only file to edit for translations.

# One block per text, then one line per language:  code = text
#   - en is required. Any language left out falls back to English on the phone.
#   - {name} is a placeholder. Keep the same names in every language, but you
#     may move them around to suit the grammar.
#   - Lines starting with # are comments.
#
# After editing, run:  python i18n/gen_strings.py
# (it writes the Android files and reports how much of each language is done)
